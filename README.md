
# To-Do List Application

## Project Description
A Python-based To-Do List Application that helps users manage their daily tasks through a simple command-line interface.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete unwanted tasks
- Save tasks permanently using JSON file storage
- Load previously saved tasks
- Handle invalid user inputs

## Technologies Used
- Python
- JSON
- File Handling
- Lists and Dictionaries
- Functions

## Project Structure

```text
TODO-LIST-APP/

└── .gitignore
```

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python main.py
```

## Data Storage
The application uses `tasks.json` to store task information. Tasks remain saved even after closing the application.
